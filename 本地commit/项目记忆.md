# Fntv-Plus 影视网页端增强 · 项目记忆

## 项目定位
把 Fntv-Plus（Electron 客户端）的影视网页端增强，做成飞牛 **FPK 应用**，注入到网页版飞牛影视（`/v`），
供"不想装客户端、只在浏览器看片"的用户使用。入口 URL 变为 `/app/fntvplus/v/`（官方桌面图标包装，对用户无感）。

## 关键架构决策
- **复用，不重写**：将 `Fntv-Plus/src/preload` 逐字复制到本项目的 `src/preload/`。
  `embyWall.ts` 在模块加载时通过 `registerHook(HookType.OnReady, handle)` 自注册；
  `src/web-entry.ts` 在 DOM ready 后 `runHooks(OnReady)` 即可启动海报墙/轮播/沉浸式美化。
- **浏览器垫片** `src/shim/electron.js` 提供 `ipcRenderer`/`shell`（`settings:*` → localStorage，其余 no-op），
  由 esbuild `alias: { electron: shim }` 注入；`process.env.NODE_ENV` 用 `define` 处理。
- **打包**：`scripts/build-userjs.mjs`（esbuild）→ `dist/fntv-plus.user.js`（IIFE，约 777KB），即 FPK 要注入的 payload。
- **注入宿主（未做）**：FPK **Go 反代** `/app/fntvplus/v/` → 回环 `127.0.0.1:<webport>/v` → HTML 注入 payload、非 HTML 透传（含 206）。
  零系统文件改动；影视升级不失效、不与 fndesk 冲突、卸载零残留。
- **后端语言 Go**（单二进制，零依赖），platform 需分 `x86`/`arm` 两包。

## 本地 commit 约定（本项目）
- 每次改动自动本地 commit + 打轻量 tag `lc-NNN`（从 `lc-001` 起，与 Fntv-Plus 仓库序列独立）。
- 只暂存文本源码（`src/`、`docs/`、`scripts/`、`demo/`、`配置`、`本地commit/`）；`node_modules/`、`dist/`、`*.log` 不入库（见 `.gitignore`）。
- **不 push**、**不带 WorkBuddy 署名**（全局 `commit-msg` hook 自动剥离 Co-Authored-By）。
- 回退：`git -C D:/GitHub/Fntv-Plus-Desktop/fntvplus checkout lc-NNN`；查 hash：`git rev-parse --short lc-NNN`；回最新：`git checkout main`。
